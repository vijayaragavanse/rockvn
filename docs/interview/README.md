# Interview Knowledge Base

One entry per technology or practice in this repository, written to be
re-read the week before an interview. Every entry is grounded in *this*
codebase — each answer can point at a real file, decision, or measurement
here, which is what separates "I've read about it" from "I've done it".

Entry structure: why it is here, the concepts that matter, likely interview
questions with strong answers, and the common mistakes interviewers probe
for.

New entries are mandatory whenever a milestone introduces a technology —
the milestone is not done without them
([definition of done](../standards/repository-standards.md#definition-of-done)).
